# Comrade Agency: изменения

Это Electron-приложение: основной процесс управляет файлами, моделями и MCP; интерфейс написан на JavaScript без сборщика. Основные данные находятся в локальном JSON. Ключи моделей и ручные заголовки по-прежнему хранятся в нём открыто: не публикуйте экспорт.

## Язык
В «Настройки → Язык / Language» доступны русский и английский. Верхнее название Comrade Agency не меняется. Тексты переписки, имена агентов, код, названия моделей и содержимое инструментов не переводятся автоматически.

## Аватарки
Откройте редактор агента и нажмите «Загрузить…». Изображение до 8 МБ декодируется, обрезается по центру и сохраняется как PNG 256×256 в данных агента. Это работает офлайн и после перезапуска.

## Microsoft
`src/reference/microsoft.json` — локальный авторский конспект с официальными ссылками, не полная копия документации Microsoft. Скачивание первичных страниц в этой сессии завершилось тайм-аутами. Поиск — в настройках; релевантные фрагменты добавляются в запрос к модели в основном процессе. База не обучает модель и не даёт ей доступ к файлам Office. Уточняйте версию и платформу. Для расширения добавляйте статьи с `id`, `title`, `tags`, `source`, `content`.

## MCP и OAuth
Установите зависимости (`npm install`) перед запуском (`npm start`). Удалённый сервер должен поддерживать Streamable HTTP и MCP OAuth. На карточке подключения нажмите «Войти в браузере». Системный браузер открывается автоматически, также доступна ссылка. Секреты OAuth хранятся отдельно, через Electron safeStorage, не передаются модели и не попадают в экспорт JSON. PKCE, discovery, resource binding, refresh и управление MCP-сеансом реализуются официальным SDK. Callback слушает только 127.0.0.1, имеет случайный порт, проверку state и тайм-аут три минуты.

Если сервер не поддерживает динамическую регистрацию, нужен публичный OAuth Client ID с поддержкой loopback redirect; не используйте секрет конфиденциального клиента в интерфейсе. Обычный вход на сайт без MCP-сервера не превращает сайт в подключение. Для Gmail, Calendar, Drive и Slack укажите адрес своего реально работающего MCP-сервера: старые примерные адреса из каталога убраны.

После входа синхронизируйте инструменты и назначьте подключение агенту в редакторе. Пустой выбор означает отсутствие доступа. Каждый вызов требует нативного подтверждения: серверные аннотации «только чтение» не считаются гарантией отсутствия изменений. «Отключить доступ» удаляет локальные токены; для полного отзыва также удалите разрешение в настройках сервиса.

## Проверки и ограничения

Автотесты: `npm install && npm test` (51 unit-тестов: хранение, i18n, справка, аватары, MCP).
Статические ассеты и ссылки: `python3 tests/check_assets.py`.
Запуск из исходников: `npm start`. Браузерный предпросмотр (без Electron): `python3 scripts/preview_server.py`.

Реальный OAuth-вход и вызовы MCP-инструментов требуют доступного сервера с поддержкой Streamable HTTP и учётной записи сервиса. Упаковку приложения (`npm run dist:mac` / `dist:win`) проверяйте на целевой ОС.
